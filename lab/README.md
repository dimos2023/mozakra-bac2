# معمل البرمجة والأمن السيبراني 🛡️

منصة تطبيقية لطلاب **الصف الثاني الثانوي (البكالوريا)** — مادة البرمجة والذكاء الاصطناعي.
الطالب بيجرب بإيده، والنتيجة بتظهر قدامه فورًا. مفيش سيرفر ولا قاعدة بيانات: كل حاجة بتشتغل في المتصفح.

## المعامل

| المعمل | الدرس | اللي بيعمله الطالب |
|---|---|---|
| التشفير المتماثل | 2-1 | قيصر + AES حقيقي، فك رسالة سرية، مفتاح غلط |
| المفتاح العام و HTTPS | 2-1 | RSA حقيقي، المتطفل، ترتيب مصافحة TLS |
| فاحص HTTPS | 2-1 | يفحص شهادة أي موقع حقيقي، ويكتب فاحص بايثون ويشغّله على الإنترنت |
| دوال التجزئة | 2-1 | SHA-256، تأثير الانهيار، باسورد مسرّب، سلامة ملف |
| التوقيع الرقمي | 2-1 | توقيع ECDSA، كشف التزوير، ترتيب الخطوات |
| المصادقة الثنائية | 2-1 | كود TOTP حقيقي كل 30 ثانية، كود منتهي، تصنيف العوامل |
| قوة كلمة المرور | 2-1 | مقياس القوة ووقت الكسر |
| جدار الحماية و DMZ | 2-2 | كتابة قواعد ومحاكاة 8 حزم، Zero Trust |
| الاستجابة للحوادث | 2-3 | المراحل الست، التصنيف، الخطر = التأثير × الاحتمالية |
| HTTP و API | 3-2 | خادم تجريبي: GET/POST/DELETE، رموز الحالة، التوكن |
| معمل بايثون | تطبيقي | 5 تحديات بتتصحح أوتوماتيك (Pyodide) |
| معمل الويب | 3-3 | HTML/CSS/JS مع معاينة حية و4 تحديات |

## النشر على GitHub Pages (مجانًا)

1. اعمل حساب على github.com واعمل Repository جديد (مثلاً `cyber-lab`) — **Public**.
2. ارفع كل الملفات اللي في الفولدر ده (Add file ← Upload files) واعمل Commit.
3. من **Settings ← Pages**: اختار `Deploy from a branch`، والفرع `main`، والفولدر `/ (root)`، واضغط Save.
4. بعد دقيقة الرابط هيبقى: `https://<اسم-حسابك>.github.io/cyber-lab/` — ابعته للطلاب.

## التجربة على جهازك

افتح `index.html` في المتصفح، أو الأفضل شغّل سيرفر محلي من الفولدر:

```
python -m http.server 8000
```

وافتح `http://localhost:8000`.

## الفحص الحقيقي من الجهاز: `tools/https_check.py`

برنامج بايثون (من غير مكتبات إضافية) بيتصل بالموقع بنفسه ويتحقق من الشهادة زي المتصفح، وكمان بيفحص إصدار TLS وتحويل http لـ https و HSTS:

```
python tools/https_check.py google.com
```

الطالب يقدر ينزّله من صفحة "فاحص HTTPS".

## ملاحظات للمدرس

- **التقدم محفوظ على جهاز الطالب** (localStorage). الطالب يكتب اسمه في الصفحة الرئيسية، ويضغط **"انسخ تقرير النتيجة"** ويبعته لك واتساب.
- معمل بايثون محتاج إنترنت أول مرة (بيحمّل بايثون ~10 ميجا).
- فاحص HTTPS بيجيب الشهادات عن طريق خدمة مجانية (`networkcalc.com`) لأن المتصفح مابيسمحش لصفحة تقرا شهادة موقع تاني. لو الخدمة وقفت، الفحص المباشر بس هو اللي هيقف — تمرين الكود على الحالات التجريبية هيفضل شغال.
- لو طالب كتب `while True` من غير نهاية الصفحة هتهنج — يعمل ريفرش (الكود بيتحفظ).
- **إضافة تحدي بايثون:** في `labs/python.html` ضيف عنصر في `CHALLENGES`، وضيف الـ id بتاعه في `tasks` بتاعة `python` في `assets/app.js`.
