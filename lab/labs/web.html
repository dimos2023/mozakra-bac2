HTML الدلالية (Semantic)

قسّم الصفحة بالعناصر اللي "ليها معنى": <header> و <nav> و <main> و <footer>، وخلّي فيها عنوان <h1> واحد بس. ده بيساعد محركات البحث (SEO) وقارئات الشاشة.

إمكانية الوصول: صور بنص بديل

ضيف صورة واحدة على الأقل <img>، واتأكد إن كل صورة ليها alt بيوصفها (للي مابيشوفش أو لو الصورة ماحمّلتش).

مثال: <img src="https://picsum.photos/300/150" alt="صورة فناء المدرسة">

JavaScript: خلّي الزرار يشتغل

لما حد يدوس على الزرار اللي الـ id بتاعه btn، الكلام جوه العنصر اللي الـ id بتاعه msg لازم يتغير.

مساعدة: document.getElementById("msg").textContent = "..."

التصميم المتجاوب (Responsive)

1) ضيف في HTML: <meta name="viewport" content="width=device-width, initial-scale=1">
2) ضيف في CSS قاعدة @media (max-width: 600px) { ... } بتغيّر حاجة في الشكل على الموبايل.
