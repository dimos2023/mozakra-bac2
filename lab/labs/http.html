📤 الطلب (Request)

📖 الـ Endpoints المتاحة
GET/api/studentsكل الطلاب
GET/api/students/{id}طالب واحد
POST/api/studentsإضافة طالب (JSON: name, grade)
DELETE/api/students/{id}حذف طالب — محتاج Authorization

200 OKتمام، وده اللي طلبته

400 Bad Requestالطلب نفسه غلط (مثلاً JSON بايظ)

404 Not Foundالحاجة دي مش موجودة
405 Method Not Allowedالطريقة دي مش مسموحة هنا

مين الطالب رقم 3؟

ابعت طلب GET للطالب اللي الـ id بتاعه 3، واكتب اسمه ودرجته.

اعمل خطأ 404 بإيدك

اطلب طالب مش موجود. الخادم هيرد بإيه؟

ضيف طالب جديد

ابعت POST على /api/students ومعاه JSON فيه name وgrade. المطلوب رد 201 Created.
جرّب كمان تبوّظ الـ JSON (امسح قوس) وشوف الرد.

الحذف محتاج صلاحية 🔑

1) حاول تحذف طالب بـ DELETE من غير صلاحية ← هتاخد 401.
2) المدرس إداك التوكن ده — ضيفه في الترويسات وجرب تاني:

Authorization: Bearer teacher-token-123
